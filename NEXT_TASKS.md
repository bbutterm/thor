# Задачи по решениям владельца (27.10)

> Решения — `GDD.md`, раздел 26. Правила работы — как в `NIGHT_TASKS.md`: блоки по порядку, у каждого блока отдельный коммит, все тесты 0 FAIL, в конце отчёт `REPORT_<дата>.md` и сборка в `builds`.

## 1. Залы: генератор + ручные арены
- Обычные боевые залы Мидгарда по-прежнему строит `tools/build_scenes.gd`.
- Сюжетные залы и арены боссов (`sven_arena`, `boss_arena` и все будущие) **выведи из генератора**. Это обычные сцены, которые правятся в редакторе. Генератор их не создаёт и не перезаписывает: заведи для них явный список-исключение и проверку.
- В `CLAUDE.md` замени предупреждение «генератор перезапишет» на правило: какие сцены генерируются, какие нет.
- Добавь в генератор 3–4 новые планировки обычных залов (GDD 16: причал с драккаром, яма-колизей, деревня, ярусы) — с вертикалью, 2–3 путями наверх и местами для удара-приземления. Проверь их в `reach_test` и `ai_test`.

## 2. Комиксовая обводка (GDD 20)
- Чёрная обводка у врагов, боссов, оружия на полу, сундуков и бочек. Вьюмодель рук — по ситуации: смотри по кадрам.
- Без новых материалов на каждый объект (правило фризов из `CLAUDE.md`). Делай общим next-pass или экранным эффектом по глубине и нормалям — выбери по замерам F3 / `perf_bench`.
- Настройка «Обводка: вкл/выкл» и толщина — в `GameSettings`, вкладка «Видео». Не забудь перевод (`tr()` + en.po).
- Кадры до и после в отчёт. Замер стоимости на толпе.

## 3. Кадр «страница комикса» (GDD 20)
- **При смерти босса и при смерти Тора:** стоп-кадр игры, 0.15 с белая вспышка, кадр «вклеивается» в рамку страницы комикса (неровный край, лёгкий наклон, растр), в углу — плашка с подписью Одина. Подпись берётся из пула по причине смерти или по боссу: `odin.page_<причина>`, `odin.page_boss_<id>`.
- Рамка — `sprites/comic/page_frame.png`, если есть (`ART_PROMPTS.txt` §5 frame), иначе процедурная.
- Длительность ~2 с, клик пропускает. Затем как раньше: смерть → диван, босс → награда.
- Выключатель «Стоп-кадр комикса» — рядом с настройками комикса.
- Тест: кадр появляется в обоих случаях и не ломает поток забега.
