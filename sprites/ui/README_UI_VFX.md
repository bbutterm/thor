# Тор: Достойная смерть — UI и VFX

Готовый компактный набор графических ресурсов. Надписи, цифры, значения HUD и название игры рисуются кодом. В игровых изображениях нет текстовых подписей.

## Состав
- 31 элемент кнопок, настроек и панелей.
- 20 HUD-ресурсов и 53 иконки: 16 оружий, 9 дверных наград, 7 категорий рун, 13 трейтов, 7 элитных модификаторов, замок.
- 66 VFX-файлов: 41 статический ресурс, 22 отдельных кадра и 3 горизонтальных стрипа.
- 2 ресурса меню: эмблема и фон.
- Всего 172 игровых файла. Контактные листы и анимационные превью не входят в это число.

## Подключение
Папка sprites/ сохраняет имена и иерархию из задания. В этом компактном архиве используются WebP вместо PNG. Загружайте пути из manifest.json либо замените расширение в своём загрузчике. PNG-оригиналы сохранены отдельно; конверсия из данного WebP обратно в PNG не восстанавливает оригинальные цветовые данные.

WebP: цветовое сжатие с потерями quality 94, альфа-канал без потерь, побитово совпадает с PNG-источником. Размеры не уменьшены при упаковке. Исходные иконки из сгенерированных листов приведены к 512×512; это не означает 512 пикселей независимой детализации исходной генерации.

manifest.json содержит ID, путь, размер, точки привязки, SHA-256, состояния и параметры из производственных метаданных. Поля png_source_path и source служат указателями происхождения, а не файлами этого компактного архива. Для загрузки используйте path. В category_metadata находятся группы анимаций, их frame_order, strip, frame_size, fps, loop и duration_ms.

### Кнопки и панели
Параметры nine_slice задаются в пикселях исходного изображения: left, top, right, bottom. Углы не растягивать; края растягивать только по своей оси. Минимальный размер должен превышать сумму соответствующих отступов. Для малого UI сначала равномерно уменьшите всё вместе с отступами.

Круглые кнопки, иллюстрированные карточки и пузыри реплик масштабируются равномерно, без 9-slice. Рамки редкости — прозрачные накладки на карточки. Плашка имени отдельная: положите panel_nameplate поверх panel_dialogue в верхнем левом углу.

### HUD
Для HP, ярости и высоты заполнение находится на холсте такого же размера, как рамка. Рисуйте заполнение первым, ограничивайте его областью fill_rect = [x, y, width, height] в пикселях исходного холста, поверх рисуйте рамку. Для горизонтального прогресса меняйте только ширину области отсечения, для вертикального — высоту снизу вверх. Не растягивайте саму текстуру на каждом значении.

### Анимации
- vfx_hit_flash: 6 кадров, 24 FPS, одноразовая вспышка, 250 мс.
- vfx_smoke: 8 кадров, 16 FPS, одноразовое расширение/растворение, 500 мс.
- vfx_fire: 8 кадров, 16 FPS, цикл 500 мс.

Стрипы: кадры слева направо, размер кадра 512×512. Есть и отдельные файлы каждого кадра. Не воспроизводите и стрип, и отдельные кадры одновременно: это альтернативные способы загрузки.

Вспышка и дым созданы преобразованием, масштабированием и затуханием сгенерированных мастер-изображений. Огонь — мягкая периодическая деформация мастера. Это согласованные анимационные последовательности, но не покадрово нарисованная анимация. Эффекты tintable=true можно окрашивать кодом; огонь, жижа, лёд и золотое кольцо сохраняют авторскую окраску.

## Превью
previews/ содержит листы из фактических файлов и анимационные превью. Надписи допустимы только здесь. Фон меню намеренно непрозрачен; остальные ресурсы имеют настоящий альфа-канал.

## Проверка и ограничения
См. qa_report.md и archive_audit.json. Проверены файлы и метаданные, не интеграция с конкретным движком или устройством. Шрифты Russo One/Bangers не включены. Сгенерированные декоративные узоры являются геометрическим орнаментом, не читаемыми словами.
