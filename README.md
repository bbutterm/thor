# Сборки «Тор: Достойная смерть»

**ThorDostoynayaSmert-windows.zip** — Windows-сборка (распаковать → запустить `ThorDostoynayaSmert.exe`).
Собрано из `main` @ 6fbf3be (ночь 26→27.10). Что внутри:
- **оружие:** 2 слота — мили (топор, меч, дубина, копьё, коса, кирка, нож) и ренж (арбалет, пистолет, ПП, автомат, обрез); Q / колесо / 1-2 — свитч, E — подобрать, R — перезарядка, зажать ЛКМ — сильный удар; сундуки после зачистки, элита роняет оружие;
- **прыжки:** удар-приземление по врагам подбрасывает (Пробел сразу — выше), прыжок на голову врагу, сам залезает на уступы, отскок от стены в воздухе;
- трейты Мьёльнира, идеальный хват, мини-босс «Толстый Свен» → выбор трейта;
- комиксовые слова, работающий hit-stop;
- диалоги, сохранение, «План тренировок»; Слава по GDD (меньше, но открытия теперь по карману).

**F3** — оверлей кадров, **F4** — папка с логом фризов и сохранением (`%APPDATA%\ThorDostoynayaSmert\`).
Начать «с нуля» (снова увидеть знакомство с Одином) — удалить там `save.json`.

Если Windows предупреждает о неизвестном приложении: «Подробнее» → «Выполнить в любом случае».
