# Сборки «Тор: Достойная смерть»

**ThorDostoynayaSmert-windows.zip** — Windows-сборка (распаковать → запустить `ThorDostoynayaSmert.exe`).
Собрано из `main` @ 698b49d (ночь 26→27.10). Что нового с прошлой сборки:
- **портреты персонажей** (твой комплект) в диалогах и пузырях реплик;
- **выбор тела** перед забегом: 9 тел со своими стилями движения (Таран, Шустрый, Прыгун, Тяжёлый, Скользящий), пассивками и изъянами; закрытые — под замком с ценой;
- **подкат** Ctrl+Shift на земле (у Солдата — рывок сам переходит в подкат);
- **Ярость**: 25 убийств сериями (окно 3 с) → 8 с берсерка; шкала внизу по центру;
- **музыка** (синтезированные заглушки): слои фон/бой/Ярость, приглушение на паузе, стингер на удар-приземление с высоты;
- **F5 / кнопка в паузе «Сообщить о лаге»** — zip на рабочий стол.
- Сборка легче: 66 МБ вместо 87.

Раньше в этой ветке: оружие мили+ренж (Q/колесо, E, R, зажать ЛКМ), прыжки по GDD 7.2, трейты Мьёльнира, комиксовые слова, диалоги, «План тренировок».

**F3** — оверлей кадров, **F4** — папка с логом фризов и сохранением (`%APPDATA%\ThorDostoynayaSmert\`).
Начать «с нуля» (снова увидеть знакомство с Одином) — удалить там `save.json`.

Если Windows предупреждает о неизвестном приложении: «Подробнее» → «Выполнить в любом случае».
