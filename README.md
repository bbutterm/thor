# Сборки «Тор: Достойная смерть»

**ThorDostoynayaSmert-windows.zip** — Windows-сборка (распаковать → запустить `ThorDostoynayaSmert.exe`).
Собрано из `main` @ eea0598 (ночь 26→27.10). Что нового с прошлой сборки:
- **интерфейс на твоей графике**: меню, HUD (HP со щитом, камни рывка, состояние Мьёльнира, слоты оружия, Ярость, руны, серебро, шкала высоты удара-приземления, стрелки на врагов за экраном), карточки рун/трейтов, ларёк, диалоги;
- **настройки** (6 вкладок): звук, мышь, **переназначение клавиш**, экран/FOV/тряска, прицел, доступность;
- **эффекты из твоего комплекта**: вспышки, искры, ихор, дым, огонь, молнии, ударная волна и трещины, лёд, линии скорости, виньетка Ярости;
- **боссы**: Толстый Свен (4-й зал, своя арена) и **Ярл Бьорн** (финал, 3 фазы, длинный дом с балконами);
- **структура забега**: 7 залов, после зачистки — **2–3 двери-награды** (руна, элита, сундук, отдых, Локи, Фрейя, испытание, **ларёк Брокка** с серебром);
- обучение от воронов в первом зале; пике и отмена удара-приземления; гвоздомёт и ракетница (открываются в Плане тренировок); все 13 трейтов Мьёльнира.

Раньше в этой ветке: руны по GDD, враги Мидгарда, элита, портреты, выбор тела, подкат, Ярость, музыка, F5 «лаг», оружие мили+ренж (Q/колесо, E, R, зажать ЛКМ), прыжки по GDD 7.2, трейты Мьёльнира, комиксовые слова, диалоги, «План тренировок».

**F3** — оверлей кадров, **F4** — папка с логом фризов и сохранением (`%APPDATA%\ThorDostoynayaSmert\`).
Начать «с нуля» (снова увидеть знакомство с Одином) — удалить там `save.json`.

Если Windows предупреждает о неизвестном приложении: «Подробнее» → «Выполнить в любом случае».
