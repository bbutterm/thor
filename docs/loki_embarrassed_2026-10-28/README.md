# Смущённый Локи

В сценах после забегов и в репликах сделки и испытания Локи использует эмоцию `embarrassed`. Раньше при отсутствии файла выбирался `neutral`. Новый `loki_embarrassed.webp` создан генерацией изображений OpenAI на основе нейтрального портрета владельца; исходные портреты не менялись. Отсутствующие эмоции по-прежнему используют neutral.

[До — neutral](before.jpg) · [После — embarrassed](after.jpg) · [Пузырь в игровом зале](bark.jpg). Сценарий `tests/extra_emotion_shots.tscn -- <папка> loki` показывает одну и ту же реплику до и после и отдельную реплику сделки в боевом пузыре. Кадры — Godot 4.6.3, GL Compatibility, Mesa llvmpipe, 1280×720; прозрачный контур проверен на фоне реальной сцены. При завершении Godot сообщил о двух неосвобождённых GL-текстурах, но сохранил все кадры и завершился с кодом 0.

Исходный WebP — 1024×1536; импорт ограничен 768 пикселями, импортированная текстура занимает 100 006 байт. `portrait_test` — 90/0, включая загрузку, прозрачность, размер, fallback и прогрев; первый запуск при выходе сообщил о двух оставшихся ресурсах, повтор с verbose завершился без этой ошибки. `dialogue_test` — 136/0. Размер итогового ZIP нужно проверить после объединения.
