# Реплики после смерти с дальнобойным оружием

`RunTracker.result(false)` ставит метку `ranged`, если активен дальнобойный слот, без записи типа оружия. Туда может попасть, например, доступный в стартовом пуле пистолет, поэтому текст `odin.death_ranged.04` больше не утверждает, что в руках был арбалет. Отдельная левая рука позволяет бросить Мьёльнир при активном дальнобойном оружии; `odin.death_ranged.03` больше не утверждает, что молот был в руке в момент смерти.

Поменяны только две реплики и их английские переводы, с прежними id и эмоциями. `python3 tools/i18n_dialogues.py --check` и статическая проверка JSON выполнены; Godot при подготовке не запускался.
