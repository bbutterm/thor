## Производительность: пока не выполнено

Сравнение с исходным `main` (`db952fa`) в одном процессе, GL Compatibility / llvmpipe, 320×180, одинаковая камера и 44 неподвижных врага (ИИ и атаки выключены). После прогрева два прохода дали медиану **117,38 / 114,17 мс** для исходного зала и **135,09 / 137,85 мс** для Н3; draw calls около 2390 → 1710. Новый зал в этом программном тесте медленнее примерно на 15–21%; проверка на целевой видеокарте отсутствует. Эксперимент с другой фильтрацией дал 130,04 / 133,51 мс и чуть более зернистый пол под острым углом: он не возвращает прежнюю скорость и не включён в проект. Требование «не хуже прежнего» остаётся открытым; эти результаты не измеряют стоимость активного ИИ.
