# Дополнительная проверка рендера Н3

Проверены две независимые гипотезы поверх `4b1ef8e`. Результаты не решают задачу «не хуже прежнего», поэтому **изменения рендера не включены в игру**.

Один процесс Godot 4.6.3, GL Compatibility, программный llvmpipe, 320×180: исходный зал из `db952fa` и Н3 переключаются с одной и той же камерой и 44 неподвижными врагами. После прогрева два прохода по 45 или 60 кадров; анимации заморожены для сопоставимости, время измеряется системными часами. Это сравнение графики, а не замер в реальном бою или на целевой видеокарте. Другие тяжёлые процессы при замерах не работали.

## 1. Более мелкие ячейки дальнего MultiMesh

В `Backdrop/Scatter` группы по 40 м разбиты на ячейки 6, 12 и 20 м. Экземпляры, меши, трансформации, материалы, слои и тени сохранены; меняется только группировка для отсечения камерой. Оригинал: 45 групп, варианты: 140, 112 и 72 соответственно.

| Вариант | Медиана, мс: проходы 1 / 2 | Draw calls |
|---|---:|---:|
| исходный main | 117,09 / 115,99 | 2487 |
| Н3, прежние группы | 151,69 / 141,07 | 1812 |
| Н3, ячейка 6 м | 137,51 / 138,42 | 1847 |
| Н3, ячейка 12 м | 139,58 / 145,75 | 1839 |
| Н3, ячейка 20 м | 135,85 / 137,07 | 1822 |

Каждый экспериментальный контрольный кадр совпал с исходным Н3 побайтно: **57 600 из 57 600 пикселей** при 320×180. Разброс времени заметен; даже лучший вариант не достигает baseline. Дополнительные группы также увеличивают draw calls и не проверены на других ракурсах и GPU.

## 2. Специализированный шейдер для горизонтального пола

Заменён только материал `Dress/FloorVisual`: формулы общего шейдера упрощены при нормали `(0, 1, 0)`, два масштаба, шум, второй слой, нормали и освещение сохранены. Остальные поверхности используют исходный материал. Экспериментальный шейдер находится в `tests/fixtures` и не экспортируется.

| Вариант | Медиана, мс: проходы 1 / 2 | Draw calls |
|---|---:|---:|
| исходный main | 123,51 / 119,96 | 2499 |
| Н3, общий шейдер | 137,99 / 135,65 | 1824 |
| Н3, шейдер пола | 138,28 / 144,36 | 1824 |

На контрольной камере совпали **57 595 из 57 600 пикселей**, средняя абсолютная разница — 0,000035 из 255 на канал: [оригинал](floor_original.png), [эксперимент](floor_special.png). При этом устойчивого ускорения нет; шейдер оставлен только в стенде.

## Повторение

```sh
XDG_DATA_HOME=/tmp/thor-room-bench LIBGL_ALWAYS_SOFTWARE=1 \
  godot --path . --fixed-fps 60 --rendering-method gl_compatibility \
  --resolution 320x180 res://tests/room_scatter_compare.tscn -- /tmp/thor-scatter-shots

XDG_DATA_HOME=/tmp/thor-room-bench LIBGL_ALWAYS_SOFTWARE=1 \
  godot --path . --fixed-fps 60 --rendering-method gl_compatibility \
  --resolution 320x180 res://tests/room_floor_shader_compare.tscn -- /tmp/thor-floor-shots
```

Нужен X11/виртуальный дисплей и изолированный CPU. `--headless` не измеряет рендер. Полученные результаты не доказывают регрессию или её отсутствие на целевом GPU; сравнение на живом бою и реальной видеокарте остаётся открытым.
