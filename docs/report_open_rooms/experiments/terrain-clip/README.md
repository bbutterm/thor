# Отсечение закрытой части дальней земли

Эксперимент на Н3: в первом зале поверхность `Dress/GroundSkirt` находится на высоте −0,05 м и простирается до квадрата ±30 м; дальняя земля `Dress/Backdrop/Ground` начинается на радиусе 29,5 м и лежит ниже. Проверено, что юбка и фон в 11 открытых сценах имеют одинаковые границы и единичные трансформации; это не доказывает, что отсечение безопасно для всех ракурсов и всех сцен.

Стенд разбивает исходные треугольники дальней земли по четырём сторонам квадрата ±30 м, исключает часть внутри квадрата и линейно переносит нормали, касательные, цвета и UV. Площадь проекции земли уменьшилась с **16 312,20 до 15 434,95 м²** (−877,26 м²), число вершин увеличилось с 240 до 480. Коллизии, материалы и игровой меш не менялись: замена существует только в стенде.

Godot 4.6.3, GL Compatibility, Mesa llvmpipe, 320×180, одна камера, 44 неподвижных врага, без активного ИИ. В одном процессе после прогрева переключались исходный зал из `db952fa`, Н3 и вариант с отсечением; для каждого варианта два прохода по 60 кадров. Игра поставлена на паузу для одинаковых кадров, системное время кадра отсортировано для медианы и p95. Других тяжёлых процессов в ходе замера не было.

| Вариант | Среднее, мс: 1 / 2 | Медиана, мс: 1 / 2 | p95, мс: 1 / 2 | Draw calls |
|---|---:|---:|---:|---:|
| Исходный зал | 148,28 / 114,68 | 145,02 / 113,74 | 176,37 / 127,77 | 2503 |
| Н3 | 148,14 / 149,43 | 147,64 / 144,82 | 172,51 / 183,78 | 1828 |
| Н3 с отсечением | 136,66 / 146,79 | 134,89 / 141,53 | 154,85 / 188,20 | 1828 |

Отсечение не вернуло скорость исходного зала во втором проходе; колебание между проходами заметное. Следовательно, требование Н3 «не хуже прежнего» не подтверждено. Это замер программного рендера без активного боя, а не результат для видеокарты пользователя. **Изменение не включено в игру.**

[Контрольный кадр](reference.png): исходный Н3 и отсечённый вариант с одной и той же замороженной камерой совпали во всех 57 600 пикселях и имеют одинаковый SHA-256 PNG `1e1a1bc1efd004be0389ac390ad8a65437c7ae6178dc6d5079fa8ea154d30b01`. Проверен только этот ракурс; до возможного применения нужны дополнительные виды, проверка перекрытия юбки в каждой сцене и реальный GPU. При выходе после завершения стенда Godot сообщил о двух неосвобождённых GL-текстурах и `ObjectDB`.

Повторить на машине с X11, без параллельной тяжёлой нагрузки:

```sh
XDG_DATA_HOME=/tmp/thor-terrain-bench LIBGL_ALWAYS_SOFTWARE=1 \
  godot --path . --fixed-fps 60 --rendering-method gl_compatibility \
  --audio-driver Dummy --resolution 320x180 \
  res://tests/room_terrain_compare.tscn -- /tmp/thor-terrain-shots
```

`--headless` не подходит для замера рендера. Полный [лог](bench.log) сохранён с ограничением размера вывода.
