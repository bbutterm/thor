# Проверки подготовленных изменений экспорта

28 октября после остановки A/B прогона проверены Python-тесты и аудит в отдельных worktree. Каждый приложенный `.txt` — полный вывод соответствующей команды; `merge-*.txt` — вывод пробного `git merge-tree`, у которого код 1 ожидаем из-за выявленного конфликта. Godot и экспорт на этом этапе не запускались.

| Изменение | Проверки |
|---|---|
| `514ccb7`: динамические изображения | 28 тестов `test_export_assets.py`, 1 тест упаковщика; аудит прошёл и отдельно показал отсроченные фоны финала и Хель. |
| `ed9db1a`: три заготовки | 12 тестов `test_export_decor.py`, 6 прежних тестов аудита; аудит исходной ветки прошёл. |
| `3cdca13`: резервный финальный кадр | 35 тестов `test_export_assets.py`; аудит отдельно показал отсроченные фон и кадр финала. Кандидат здесь не применяется. |
| Объединение 514 + ed9 | 28 тестов аудита диалогов, 12 защиты декора, 1 тест упаковщика; объединённый аудит прошёл. |

Пробное объединение `514ccb7` с `ed9db1a` выявило конфликт `tools/check_export_assets.py`. В объединённом варианте сохранены оба импорта, обход всех исходных данных и обе проверки для каждого preset. Отдельное пробное объединение `ed9db1a` с `3cdca13` выявило конфликты в том же аудите и `export_presets.cfg`: в случае применения резервного кандидата нужно сохранить обе группы исключений. Файл `sprites/story/finale.webp` в текущем объединении остаётся в экспорте.

Аудит не доказывает полную недостижимость отложенных сцен при изменённых сохранениях или произвольной динамике и не исследует бинарные glTF. После последующей интеграции нужно выполнить импорт и тесты Godot, а также реальный экспорт, сравнить размер ZIP и проверить изображения залов. Данные аудита не означают, что финал уже подключён.
