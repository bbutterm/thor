# Статическая оценка текста карточек

`measure.py` — сохранённая копия скрипта, использованного при проверке описаний Пике, Ступеньки, Берсерка и Кузнеца. Скрипт читает текущие `.tres`, перевод `data/i18n/en.po` через `tools/i18n_extract.py` и игровой шрифт `fonts/RussoOne-Regular.ttf`.

Запуск из корня репозитория с Python 3 и Pillow; при подготовке использовался Pillow 12.3.0:

```sh
python3 -m pip install 'Pillow==12.3.0'
PYTHONDONTWRITEBYTECODE=1 python3 docs/body_trait_text_2026-10-28/measure.py
```

Скрипт оценивает по уровням и языкам тексты двух приёмов для карточки шириной 340 px, а также перенос описаний двух тел. Он моделирует перенос по словам, метрики шрифта и размеры обводки; при переполнении расчётного бюджета или слишком длинном слове завершается с ошибкой. Ожидаемые значения для подготовленных текстов — до 164 px при бюджете высоты 185.5 px для приёмов, до 298 px при бюджете ширины 334 px для описаний тел.

Pillow и Godot могут по-разному переносить и измерять строки; эта оценка не доказывает отсутствие обрезки в игре и не является визуальным кадром. Фактическую раскладку проверяет `tests/trait_test.tscn`, а внешний вид — просмотр игровых кадров.
