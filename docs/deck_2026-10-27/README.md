# Геймпад и 1280×800 — 27.10

## Что изменено

- A подтверждает, B возвращает и Start ставит паузу; пункты меню, выбор рун, приёмов, наград и ответов получают фокус. D-pad перемещает выбор, включая ларёк и диалоги. В журнале диалога View открывает запись, правый стик прокручивает её, B закрывает; открытый журнал не даёт случайно выбрать ответ под ним. Y пропускает сцену после защиты от случайного нажатия.
- В «Настройки → Клавиши» отдельные колонки для клавиатуры/мыши и геймпада. Можно назначить кнопку или направление стика, в том числе для камеры. Конфликтующая прежняя кнопка снимается и её действие остаётся в списке для нового назначения. Start зарезервирован для паузы и отмены захвата. Сбросы разделены; настройки сохраняются в `settings.cfg` по секциям `[input]` и `[pad_input]`.
- Подсказки обучения, Мьёльнира, подбора и приёмов показывают текущую привязку последнего использованного устройства. В ларьке D-pad ↑ не закрывает экран: это навигация, хотя на эту же кнопку по умолчанию назначено взаимодействие в игре.
- Списки тела и плана тренировок прокручиваются за фокусом, после покупки фокус не теряется. Экран тела умещается в 1280×800, его описание прокручивается правым стиком.

## Кадры 1280×800

GL Compatibility, Mesa llvmpipe, кадры сняты на Xorg с отдельным виртуальным экраном 1280×800. Это рендер пользовательского интерфейса; фон 3D во время съёмки отключён.

На кадре ларька пока процедурные портреты Брокка и Эйтри: изображений этих персонажей на момент съёмки в проекте не было.
На кадре выбора тела подпись старого счётчика «рывков» и описание его перезарядки ещё не включают отдельное исправление согласования с рунами Мьёльнира.
