# Эйтри после выбора наковальни

Раньше реплика Эйтри появлялась одновременно с `TraitPick`: затемнение и карточки почти полностью скрывали пузырь. На [прежнем кадре](../seven_emotions_2026-10-28/shots/eitri_anvil.jpg) выбор открыт, а пузырь находится под ним. После исправления [выбор стихии](01_picker_before_choose.png) сначала показывается без реплики; [после подтверждения](02_eitri_after_confirmed_fire.png) карточка исчезает и пузырь Эйтри читается целиком. Скриншоты не являются попиксельным A/B: сняты разными стендами и в разные моменты. Старый стенд для воспроизводимости напрямую задавал фразу пузырю под уже открытым выбором.

Стенд запускает настоящий `Game` на `d95bb11` и настоящую цепочку `RewardFlow.grant → TraitPick.choose(0) → Game._on_trait_picked → Dialogue.bark_pool`. Для воспроизводимости в памяти принудительно заданы награда `anvil`, единственный вариант стихии `fire` («Огонь») и исходная строка пула `dwarves.eitri.04` — «Угу-угу.» с эмоцией `smug`. Защитное ожидание клика пропущено через `_open_time`. Зачистка зала и ввод игрока не разыгрывались.

Стенд проверил отсутствие реплики при открытом выборе, одну реплику после подтверждения, закрытое окно, снятую паузу, имя и текст в пузыре и его непрозрачность больше 0,5. Оба кадра получены на 1280×720, GL Compatibility, Mesa llvmpipe; визуально пузырь и его текст не закрыты карточками. Это проверка отображения, не измерение производительности. В рендере видны серые модели оружия; вопрос их материалов здесь отдельно не проверялся.

Исходные PNG и стенд: [открытый выбор](01_picker_before_choose.png), [пузырь после выбора](02_eitri_after_confirmed_fire.png), [GDScript](anvil_after_shot.gd), [сцена](anvil_after_shot.tscn). Для воспроизведения скопировать сцену и скрипт из этой документации в `tests/` отдельной копии проекта, выполнить импорт и запустить её с отдельным `XDG_DATA_HOME` и ограничением журнала. [Полные ограниченные логи](logs.zip) содержат первый и повторный импорт, съёмку и Xorg. Первый импорт сообщил об ещё не созданном импортированном шрифте Russo One; повторный завершился с кодом 0 без ошибок. Съёмка завершилась с кодом 0; при выходе Godot сообщил об утечке двух GL-текстур по 349 524 байта и объектов ObjectDB. V-Sync и Screen-space AA не были доступны на использованном рендерере.
