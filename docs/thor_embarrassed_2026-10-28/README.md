# Смущённый Тор

В диалогах и боевых репликах Тора используется эмоция `embarrassed`, но раньше для неё не было портрета: отображался `neutral`. Добавлен `thor_embarrassed.webp`, созданный генерацией изображений OpenAI на основе нейтрального портрета владельца; исходные изображения не менялись. Неизвестные эмоции по-прежнему используют нейтральный портрет.

[До — neutral](before.jpg) · [После — embarrassed](after.jpg) · [Боевой пузырь](bark.jpg). Кадры сняты в диалоге и игровом зале при 1280×720, Godot 4.6.3, GL Compatibility, Mesa llvmpipe; воспроизведение — `tests/thor_embarrassed_shots.tscn`. Фон диалога виден через прозрачный контур, лицо в боевом пузыре читается. При завершении Godot сообщил о двух неосвобождённых GL-текстурах, но сохранил все кадры и завершился с кодом 0.

Портрет добавлен в прогрев наряду с доступными эмоциями Тора: Тор может произнести `thor.whine` в бою после большого урона. Исходный WebP — 1024×1536, импорт ограничен 768 пикселями; импортированная текстура в проверке занимает около 113 КБ. Размер окончательного ZIP после объединения нужно проверить заново. `portrait_test` прошёл 88/0, включая загрузку, прозрачный угол, ограничение размера, нейтральный fallback и прогрев.
