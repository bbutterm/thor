# Тор: Достойная смерть — заметки для агента

Прототип рогалик-шутера от первого лица. Godot **4.6.3** (не .NET), физика Jolt, GDScript со статической типизацией. Общение с владельцем — на русском.

Этот файл — карта и общие правила. Подробности (что лежит в папке, публичный API, типовые задачи, какие тесты её проверяют) — в `CLAUDE.md` внутри папок; Claude Code подгружает их сам при работе в папке. Перед задачей прочитай `CLAUDE.md` той папки, которую трогаешь.

## Общие правила
- **Фризы.** Не создавай материал на каждый эффект/удар: новый материал = компиляция пайплайна (Forward+), а когда последний материал вида умирает, его пайплайны выкидываются. Бери общий (`FX.fx_apply`, `WeaponMeshes.mat`, `HumanoidModel._tinted`, `WorldArt.material`), меняй вид через per-instance (`set_instance_shader_parameter`, `GeometryInstance3D.transparency`, оверлей `shaders/hit_flash.tres` у врагов). Новый вид эффекта — добавь его в `ShaderWarmup`. Новые ассеты персонажей/оружия/звуков — в папки из `AssetCache.DIRS`. В шейдерах эффектов альфу **умножать** (`ALPHA *= …`), а не присваивать — иначе не работает `GeometryInstance3D.transparency`; в GL Compatibility прозрачность идёт через instance uniform `fade` (`FX.sync_fades`). Номинальный буфер GL — 4096 ячеек, блок экземпляра — 16, до 256 блоков при свободном буфере; запас зависит от настроек и глобальных параметров. Счётчик F3 и `tests/perf_bench.tscn` видит только текущие override/overlay по текстовому признаку, а не занятые слоты. Снятие материала у свободного узла пула не гарантирует освобождение блока до удаления RID; переполнение внутри одного зала остаётся открытым ([проверка](docs/report_open_rooms/experiments/one-room-uniform/README.md)).
- **Генератор.** Сцены игрока, врагов, бочек, обычных боевых залов, зала-ларька, UI и `scenes/game.tscn` генерирует `tools/build_scenes.gd` — меняешь их структуру, правь генератор и перезапускай его (коммить только намеренно изменённые .tscn, шум `unique_id` откатывать по одному файлу). **Арены боссов и сюжетные залы — ручные сцены** (`MANUAL_SCENES`): генератор их не трогает. Подробно — `tools/CLAUDE.md`, `rooms/CLAUDE.md`.
- Блоки уровней — StaticBody3D, не CSG (CSG давал провалы сквозь пол в первые кадры).
- **Слои физики:** 1 world, 2 player, 3 enemies, 4 props, 5 projectiles, 6 triggers, 7 debris.
- Вьюмодель рук — слой отображения 2, отдельный SubViewport (`Head/Camera/ViewmodelContainer`).
- **Урон Тора по врагу — только через `player.deal_damage(target, dmg, knock, source)`.** Урон по Тору — перед `take_damage()` отметь источник в `RunTracker` (`run/CLAUDE.md`).
- Все «ощущенческие» числа — `@export`; при изменении обнови `TUNING.md`.
- Звуки в `sounds/sfx/` синтезирует `tools/make_sfx.py`.
- `_kit_original/` — исходная демо-сцена кита, игнорируется Godot (`.gdignore`).
- Запас моделей под новые миры (в игре пока не используются, исключены из экспорта в `export_presets.cfg`): `assets/kaykit/` (скелеты KayKit + анимации Rig_Medium — свой скелет, не UAL), `assets/kenney/graveyard/` (кладбище, склепы), `assets/quaternius/animals/` (волк, орёл, FBX). Кандидаты и лицензии — `ASSET_CANDIDATES.md`. Используемые модели описаны в `enemies/` (персонажи), `weapons/` (оружие, Мьёльнир), `rooms/` (деревня, пропсы, корабль), `player/` (руки).

## Локализация (ru основной, en второй)
- Ключ перевода = сама русская строка. Интерфейс и данные — `data/i18n/en.po` (gettext, подключён в project.godot, `locale/fallback="ru"`: нет перевода → русский). Язык — настройка `[text] language` (`GameSettings`, вкладка «Интерфейс»), включает `I18n.apply` (`scripts/i18n.gd`) сразу и в `apply_startup`; в тестах язык из файла не читается (всегда ru).
- В коде: `tr("Русская строка")` в узлах/ресурсах, `I18n.t("…")` в статических функциях; шаблоны — `tr("СЛАВА %d") % n` (не склеивать «"Слава: " + x»). Данные (.tres) переводятся при показе: `tr(def.title)` — .tres не трогаем. Подписи в `const` (вкладки, действия) — `tr()` при показе. Не называй локальные переменные `tr`.
- **Новая строка:** написать `tr("…")` → `python3 tools/i18n_extract.py` (добавит ключ в en.po с пустым msgstr; `--check` — отчёт) → вписать msgstr. Подстановки `%d/%s` в переводе — те же.
- Диалоги: `data/dialogues/en/<файл>.json` (`{"lines": {id реплики: {"ru", "en"}}, "speakers": …}`, ответ Тора — «id/выбор»), шаблоны и покрытие — `python3 tools/i18n_dialogues.py [--check]`; подставляет `Dialogue.localize_line` (реализация — `scripts/dialogue/dialogue_locale.gd`; pool_lines/expand), имена — прямо в `Dialogue.speakers`. Подписи выборов — в en.po.
- Смена языка на лету: экраны, собранные кодом, ловят `GameSettings.events.changed("text", "language")` и пересобираются (меню, пауза, настройки) или обновляют подписи (`HUD._retranslate`). Комикс-слова всегда английские (`words_<язык>` в `data/comic_words.json` — для своего языка).
- Проверка: `i18n_test` (в т. ч. ловит русские литералы без `tr()` в `ui/*.gd`). Кадры на английском: `… res://tests/ui_shots.tscn -- <папка> en`.

## Проверки (запускать после изменений)
```
godot --headless --path . --import                       # всегда после слияния/переключения веток
godot --headless --path . res://tools/build_scenes.tscn  # если менялись генерируемые сцены
python3 tools/run_tests.py --changed                     # тесты по изменённым файлам (карта tests/test_map.json)
python3 tools/run_tests.py --all                         # все tests/*_test.tscn в 4 потока (~4 мин)
```
Правило: перед заливкой в `main` — **все** `tests/*_test.tscn`, у каждого в конце строка «ИТОГ … 0 FAIL», без SCRIPT ERROR. Логи тестов обрезай (`… 2>&1 | head -c 50000000 > log`). Что проверяет каждый тест, кадры, фризы с рендерингом и бот — `tests/CLAUDE.md`. Сборка Windows и проверки экспорта — `tools/CLAUDE.md`.
