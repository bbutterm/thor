## Как посмотреть коммиты

В клоне проекта сначала получите историю `main` и `builds`, указанную в `github-refs.txt`, и проверьте bundle. Пути ниже замените на расположение скачанного файла:

```bash
git fetch origin main builds
git bundle verify /путь/local-commits.bundle
git bundle list-heads /путь/local-commits.bundle
# Загрузить конкретный указатель для просмотра, без автоматического создания всех веток:
git fetch /путь/local-commits.bundle refs/heads/codex/strict-font-bootstrap
git log --oneline FETCH_HEAD
```

Указатели, начинающиеся с `refs/night-checkpoint-temporary/`, — имена внутри архива для снимков GitHub и отдельного checkout; на сервер они как ветки не публиковались. Если указатель отсутствует в списке bundle, проверьте его хеш в `local-refs.txt`: такой коммит уже входит в историю исходных `main` или `builds`.

Чтобы восстановить незакоммиченные файлы конкретной папки, сначала перейдите в отдельном чистом checkout на хеш из её `head.json`, затем примените при наличии `git apply --index staged.patch`, после него `git apply unstaged.patch`, и скопируйте содержимое `untracked/` в корень checkout. Перед применением проверьте изменения: эти эксперименты могут быть неполными и пересекаться с уже перенесёнными исправлениями.
